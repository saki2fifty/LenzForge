# Historical source

This directory preserves the original setup scripts and superseded backend components for reference. These scripts target older tool versions and deployment paths and are not used by the current application. Run the repository-root `Setup.ps1` and launchers instead.

The previous Godot project is under `viewer/legacy/` and excluded from import with `.gdignore`. Historical project plans and the original README are under `docs/archive/`. Git history also preserves the complete original import.
